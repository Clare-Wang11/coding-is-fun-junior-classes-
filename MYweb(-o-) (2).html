Guessing Game

Guessing Game. This was a guessing game. It's about a treasure box named Clare. At the start of the game, Clare greets you. You must guess the correct number to open the chest. You get to choose the limit of the number. When you guess an incorrect number, Clare should give you a hint. When you guess the number correctly you win, and you get the treasure, which is the number you guessed correctly. This game is finished. Made using Python.

Turtle Fireworks

Turtle Fireworks. This was a project that used Python Turtle to make fireworks. First, you draw the firework box. Then, the turtle changes into a pellet shape. The pellet/turtle flies into the sky and explodes by increasing its size. Finally, other turtles appear and draw the fireworks. This project was one of my favorites because it was lots of fun making the fireworks. The next class, we got to see our classmates' fireworks. This project is finished. Made using Python. It used python turtle. If you want to see the firework code, and the turtle making the firework, click on the image.

Arduino

Social Distance Detector. This social distance detector has an OLED that displays distance (but mine sadly broke), an ultrasonic distance sensor, three LEDs and resistors, a breadboard, many wires, and an Arduino UNO. If the distance is smaller than 10 centimeters, the red LED will light up. If it is between 10cm and 20cm, then the yellow LED will light up. Else, the green LED will light up. This was coded using Arduino IDE. The project is mostly finished, but I still can’t manage to get accurate measurements. If you want to see what is in the arduino kit that we used, click on the image
